# An Analogy Has an Expiration Date

**Status:** English working draft | **Theme:** G. Writing, explanation, and representation | **Candidate tags:** philosophy-of-science, education

Calling a computer's storage memory helps someone understand that information can persist after an operation ends. It becomes a less useful analogy when we expect the computer to remember what is relevant in a particular situation. The first comparison establishes a relationship. The second quietly extends it to a different capability.

The same issue appears when we call a model a colleague or describe a robot's training as practice. Calling storage memory can help someone understand that information persists. It does not tell us whether the stored information will be recalled in the right situation. Calling an agent a colleague can help describe a division of work. It does not establish that the agent has the responsibilities or commitments of a colleague.

A good analogy lets us transfer a particular understanding. We should be able to say which relationships travel and where the comparison ends. If I describe a design space as a landscape, for example, the image helps me think about searching among alternatives. I should be more careful if the image leads me to assume every design has a meaningful elevation on a common scale.

Calling a design space a landscape, for instance, can help us understand the idea of searching among alternatives. It gives us little reason to assume that every design has an elevation on a single common scale. If the task involves several incompatible purposes, the relation that made the analogy useful may end precisely where the question of value begins.

This is especially important in arguments about intelligence. A familiar word can make it appear that a machine has acquired all the abilities associated with a human activity, when a particular experiment established only one of them. It can also cause us to miss a capability because the system realizes it in an unfamiliar way.

The value of an analogy can survive our discovery that some of its implications fail. Once it has helped us understand one relationship, we can examine the other relationships of the system more directly. A good explanation should make it possible to recognize that moment, rather than require the new technology to keep behaving like the familiar one.

## Editorial source notes

Reading leads: Dedre Gentner, Structure-Mapping: A Theoretical Framework for Analogy (1983); Lakoff and Johnson, Metaphors We Live By (1980). Develop paired cases where a useful analogy supports a justified inference and an unjustified one.
