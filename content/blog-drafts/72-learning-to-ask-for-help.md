# Learning to Ask for Help

**Status:** English working draft | **Theme:** J. Robotics, control, and situated intelligence | **Candidate tags:** robotics, participatory-design, ai

A robot's request for help can give another person work they were not expecting to do. If the request identifies a specific uncertainty and offers a way to resolve it, that work may be quite small. If it simply announces failure, the person may have to diagnose a task they thought they had delegated.

Suppose a robot is preparing a table and encounters a container it cannot open. A useful request for help would tell the person what the robot has already tried, where it is uncertain, and what small action could allow the task to continue. A general announcement of failure gives the person the additional work of diagnosing the problem.

There are several kinds of help a robot might need. It can ask for missing information, request physical assistance, seek permission, or invite a person to choose among several outcomes. Treating these as one category obscures the responsibility that a request transfers to the user.

A request for permission should not be evaluated as though it were a failure of perception. The robot may know exactly how to perform an action and need another person's authorization to perform it. Making that request brief and understandable can be an improvement even if the robot's physical capability remains unchanged.

Improvements in sensing and manipulation can remove the need for some requests. The requests that remain may become more particular to the setting. A system could be very good at sensing and manipulation yet need to ask who is allowed to use an object in a shared environment.

The number of requests is a poor general measure of the quality of help-seeking. I would also want to know what each request transferred to the person and whether the person could respond without taking over the entire activity. A capable robot should be able to turn an appropriate request for assistance into a useful part of collaboration.
