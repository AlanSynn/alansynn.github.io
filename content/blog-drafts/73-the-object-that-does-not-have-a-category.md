# The Object That Does Not Have a Category

**Status:** English working draft | **Theme:** J. Robotics, control, and situated intelligence | **Candidate tags:** robotics, ai

Imagine a robot trying to lift a small lid. The usual tool is missing. Nearby is a piece of metal that has an appropriate shape for the task but no familiar name. A person can recognize a possible use for it without knowing what the object was originally made to do.

This situation is interesting because object recognition and tool use come apart. A category can provide a useful starting point for understanding what an object might do. The actual task may depend on properties that cross categories: a thin edge, a rigid surface, a particular length, or a way of being held.

A system that relies too heavily on names could overlook a useful object. Another system might investigate its geometry and material but fail to recognize the purpose of the action. A capable agent needs to connect these descriptions rather than assume that one kind of recognition is enough.

There are limits to improvisation. A tool that looks appropriate may be fragile, sharp, or unsuitable for a particular load. The system needs enough evidence to determine whether using it is permissible. We should not reward a creative choice that ignores important physical or safety constraints.

I think this is a promising place to study the relation between visual intelligence and action. We can ask whether a robot can discover a useful property of an unfamiliar object under bounded conditions. Such an experiment would reveal something different from whether it can recognize a larger number of named categories.
