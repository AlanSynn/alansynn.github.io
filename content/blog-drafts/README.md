# Blog editorial draft library

**Status: unpublished editorial material.** This directory is deliberately outside the Astro blog collection at `content/blog/`. It contains 136 English essays in different editorial states: 20 long-form editorial manuscripts and 116 short drafts requiring expansion. None is certified for publication.

The library starts from the existing blog's concern with how research produces knowledge, how fields change, and how AI changes the relationship between a capability and a person's contribution. It also develops independent questions in evidence, embodied intelligence, design, graphics, fabrication, and education. Avoid turning all of these essays into variations of the same AI career argument.

The latest revision expands 20 essays to standalone long-form manuscripts and adds source and claim notes. The remaining 116 preserve their previous short prose or working argument. The original groups and numbering are unchanged. The numbers are editorial identifiers, not publication order.

## Editorial standards and workflow

- Each essay needs one strong claim with a specific mechanism and at least one serious alternative explanation. Keep the predictions accountable: distinguish present evidence, interpretation, and extrapolation.
- Use an actual research paper or concrete scene when it changes the argument. Hypothetical examples must remain identifiable as such. Do not fabricate first-person experiences.
- A qualitative observation, a visual artifact, a subjective rating, and a qualitative study are distinct forms of evidence. Match the evidence to the claim.
- The primary hypothesis is that executable, repeatable quantitative competition will increasingly be dominated by machines; do not turn every essay into a defense of human-exclusive qualitative work. Preserve the possibility of automation in qualitative inquiry while considering the proliferation of plural values and niches.
- Source notes identify checked starting material (sometimes only an abstract or project page) and reading leads that still need investigation. They are not a completed bibliography or a publication-level citation audit.
- Use the existing English blog voice: cohesive paragraphs, concrete examples, explicit reasoning, no em dashes, no invented personal history. Avoid formulaic contrast and repeating one thesis across the whole library.
- Before publication, expand and review the selected editorial draft. Verify the actual paper and scope of each cited result, and compare related posts to remove repetition.
- Convert the finished essay to a single Typst file in `content/blog/` using the shared `/content/blog.typ` template, with a stable slug, nonempty title and description, an appropriate date, and two or three registered tags. Set `draft: true` if it is intended to be an unlisted preview. An unlisted preview is still directly reachable after deployment. Use `draft: false` only on explicit publication approval.
- Keep this directory outside the rendered collection. Its files are working material, not website pages. The GitHub repository itself is public; this directory is not a private workspace.
